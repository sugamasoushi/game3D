# フィールド戦闘（今の仕様のまとめ）

コマンド戦闘とは別に、マップの上でそのまま戦う仕組みの全体像。2026-11-05 時点。
細かい決まりの正本は [00-AI引き継ぎ.md](00-AI引き継ぎ.md) の「4.19 戦闘の土台」の小節（フィールドアタック GS-295・敵シンボルが自分から動く GS-296・GS-303〜306）。仕様を変えたら両方を直す。

---

## 1. 全体の考え方

- フィールドでは、こちらも敵も**攻撃を当て合える**。ただし、当てただけでは戦闘は始まらない。
- **コマンド戦闘が始まるのは、主人公が敵シンボルに触れたときだけ**（今までどおり）。
- フィールドで削った HP はコマンド戦闘に持ち込める。コマンド戦闘からは特技「撤退」でフィールドへ戻れる。
- 広い場所では、フィールドで削る・巻き込みが増えるなど、フィールド戦闘が活きる。狭い場所では、敵が並べる数が減る・範囲の技を避けにくいので、コマンド戦闘の方が有利になる。

| 段階 | 中身 | 番号 |
| --- | --- | --- |
| 土台 | 味方のフィールドアタック（☐） | GS-295 |
| 土台 | 敵シンボルが気づいて追う・逃げる | GS-296 |
| 1 | 敵のフィールド攻撃（範囲の技・予兆の赤いマス） | GS-303 |
| 2 | その場で戦う・巻き込み・撤退 | GS-304 |
| 3 | 仲間の作戦（戦わない／移動・迎撃／移動・攻撃／自由に戦闘／待機・迎撃） | GS-305 |
| 4 | 加勢する NPC | GS-306 |
| 追加 | イベントの戦闘から撤退して追われる・逃げられない戦闘・隊列の交戦中 | GS-307 |

## 2. 操作

| 操作 | キーボード | ゲームパッド | 仮想パッド |
| --- | --- | --- | --- |
| フィールドアタック | X | ☐（2） | □ |

C キーで当たり判定の線が出る仕組みは 2026-11-05 にゲームから外した（マップエディタの「表示 → 当たり判定」は残っている）。

## 3. 味方のフィールドアタック

- ☐ で**先頭の仲間**が攻撃する。中身はその人の「使う技」（`party.json` の `fieldAttack`）。選んでいない・まだ覚えていない・フィールドで使えない技なら素手。
- 技の形は 3 つ（`skills.json` の技の `field.type`）。
  - **近接**（`melee`）: 目の前を叩く。
  - **飛ばす**（`shot`）: 向いた方へ飛ばす。壁や人に当たると消える。
  - **範囲**（`area`）: 決めたマスにいる敵シンボルみんなに当てる。味方が使うときは予兆なし。
- ダメージは戦闘と同じ計算（攻撃力 ＋ 技の威力 − 敵の守り。最低 1）。
- 当たった敵は **2 秒怯む**。ただし**まだ気づいていない敵**（うろついている・帰る途中）は、その場で気づいて **0.5 秒**で動き出す（追う敵も、襲ってこない敵も追ってくる。逃げる敵は逃げる）。怯んでいる敵に触れると**先制攻撃**（1 ターン目は味方だけが動く）。
- 技に MP を付けられる（既定 0）。足りなければ撃てない。
- マップごとに禁止できる（`maps.json` の `fieldAttack: false`）。

### フィールドで倒したとき

| その敵の様子 | 経験 | お金 |
| --- | --- | --- |
| 交戦中（下の 4.） | `rates.fieldEngaged` 倍（既定 1.0） | `rates.fieldKill` 倍（既定 0.5） |
| 交戦中でない | `rates.fieldKill` 倍（既定 0.5） | `rates.fieldKill` 倍（既定 0.5） |

- 端数は切り捨て。経験は仲間全員に入る。シンボルは消え、マップに入り直すと戻る。
- 討伐（依頼）と図鑑にも数える。

### 削った HP の持ち越し

- 削った敵に触れて戦闘になると、その敵は**減った HP のまま**出る（お供は満タン）。
- 減った HP は**そのマップにいるあいだだけ**覚える。セーブには入れない。

## 4. 「交戦中」とは

交戦中は 2 つある。**隊列の交戦中**（GS-307）と、**敵シンボル 1 体ずつの交戦中**。

### 隊列の交戦中

- 始まる: 敵の範囲の技が仲間か加勢 NPC に当たった、またはフィールドアタック（仲間・加勢 NPC を含む）を敵シンボルに当てた。**気づかれただけでは始まらない**。
- 終わる: 気づいている敵シンボルがいなくなって、最後のやり取りから 4 秒たった。マップが変わっても終わる。
- イベントの戦闘から撤退して追われているあいだ（下の 7.）は、いつも交戦中。
- **交戦中のあいだ、左上に隊列の HP の帯を出し続ける**（歩けるときだけ）。帯が出ていることが交戦中の印。
- 交戦中にコマンド戦闘になったら、近くの敵シンボルを**気づいていなくても**巻き込む（下の 6.）。

### 敵シンボル 1 体ずつの交戦中

`GameView` の `symbolEngaged`。その敵が交戦中になるのは、次のどれかのとき。

- 主人公に気づいた（「！」）、追っている、逃げている、見失って探している（「？」）
- 範囲の技を構えている、または出した直後の間

うろついているだけの敵・気づいていない敵は交戦中ではない。

使っている所:

- フィールドで倒したときの経験の倍率（上の 3.）
- 巻き込み（下の 6.）で加わる敵（隊列が交戦中でないとき）
- 仲間の作戦「移動・迎撃」で狙う敵（下の 8.。移動・攻撃・自由に戦闘は気づいていない敵も狙う）
- 隊列の交戦中が続くか（気づいている敵がいるあいだは終わらない）

交戦中の BGM の切り替えや、メニューなどの制限は無い。

## 5. 敵のフィールド攻撃

### 気づいて動く（土台）

敵シンボルの `mapNpcs.json` の `notice` で決める（台帳エディタ「マップ構成」→ NPC の設定「気づいたら」）。

| 項目 | 意味 | 既定 |
| --- | --- | --- |
| `act` | 追う（`chase`）／逃げる（`flee`）／格下なら逃げる（`fleeWeak`） | — |
| `see` | 気づく距離（マス）。`see`＋3 マス離れると見失う | 4 |
| `view` | 前だけ（左右 60° ずつ）／全方向 | 前だけ |
| `speed` | 追う・逃げる速さ（マス／秒） | 3 |
| `leash` | 置き場から離れてよい距離 | 6 |
| `gap` | 格下と見るレベル差（`fleeWeak` だけ） | 5 |
| `after` | 見失ったら：戻る／その場に残る／消える | 戻る |

- `notice` を書いていない敵（襲ってこない敵）は、見えても気づかない。**叩かれたら**（仲間・加勢 NPC の攻撃も）その場で「！」を出し、0.5 秒で追ってくる（2026-11-06。追い方は上の表の既定の値。見失って戻ったら、また襲ってこない敵に戻る）。逃げる敵は叩かれても逃げる。
- 壁ごしには気づかない。回り込みはしない（物陰で撒ける）。
- マップに入った直後と、会話・メニュー・戦闘が終わってから 2 秒は気づかない。
- 後ろから触れられると**不意打ち**（1 ターン目は敵だけが動く）。

### 範囲の技で攻める（段階 1）

- 使うのは、敵の台帳の技のうち `field.type` が `area`（範囲）の技だけ。無ければ追って触れるだけ。
- 範囲の技を持つ敵は、追いかけて**隣のマスで構える**（主人公のマスへ踏み込まない）。
- 流れ:
  1. 気づいてから 0.6 秒は出さない。
  2. マスに着いたとき、範囲に仲間が入る技があれば、止まって床に**赤いマス**（予兆）を出す。終わりに近いほど速く明滅する。
  3. 予兆が終わったとき、**範囲にいる仲間みんな**に当てる。
  4. 0.4 秒止まってから追うに戻る。次に出せるのは `interval` 秒後。
- 予兆のあいだに怯ませる・見失う・会話などで歩けなくなると、取りやめ（1 秒は出さない）。
- 当たる相手: 先頭、付いて歩く仲間、離れて動く仲間、加勢 NPC。倒れた人・高さが 1 マスを超えて違う人には当たらない。
- 範囲の技の設定（`skills.json` の `field`）:

| 項目 | 意味 | 範囲 | 既定 |
| --- | --- | --- | --- |
| `cells` | 範囲のマス。`[横, 前]`。使う人が `[0,0]`、上向きの形で書く（向きに合わせて回る） | -6〜6、1〜64 個 | `[[0,1]]` |
| `windup` | 予兆の秒数 | 0〜5 | 0.8 |
| `interval` | 次に出すまでの秒数 | 0.5〜30 | 3 |

  台帳エディタ「戦闘」→ 技の「フィールドでの使い方」で、13×13 の升目をクリックして範囲を描ける。
- 今の台帳の例: なぎはらい（`sweep`）＝目の前の横 3 マスと左右、予兆 0.8 秒、次まで 4 秒。使う敵はグレートベア（今は追う敵シンボルとしては置いていない）。

### 触れたときの扱い

- 範囲の技を持つ敵が**向こうから隣に来ただけでは**戦闘にならない。
- **主人公が敵の方を向いて接する**か重なれば戦闘になる。なので、敵の方を向いていれば技を受ける前に戦闘へ入れる。背を向けている・横や斜めから来られると技を受ける。

### 受けたダメージ

- 戦闘と同じ計算（敵の攻撃力 ＋ 技の威力 − 仲間の守り）。赤い数字と、左上に隊列の HP の帯（4 秒）。
- HP 0 で倒れる。先頭が倒れたら、倒れていない人が先頭になる。**みんな倒れたらゲームオーバー**。

## 6. コマンド戦闘へ入る（段階 2）

### その場で戦う

- 敵シンボル・ランダムエンカウントの戦闘は、**主人公の立つマスを舞台の真ん中**にして戦う。壁や天井の下のマスには立たない。
- 触れた組すら立てない狭さ（家の中など）なら、その戦闘だけマップの舞台の点で戦う。
- マップごとに、いつも舞台の点で戦うようにできる（`maps.json` の `battleAt: "stage"`。台帳エディタ「マップ構成」→ 戦闘）。
- **イベントの戦闘はいつも舞台の点**。

### 巻き込み

- 敵シンボルに触れたとき、近く（`fieldBattle.join` マス以内。既定 4）で**こちらに気づいている**敵シンボルも、近い順に戦闘へ加わる。
- **隊列が交戦中なら、気づいていない敵シンボルも加わる**。ランダムエンカウントでも同じく巻き込む（巻き込んだ敵シンボルがいれば、その戦闘は撤退できる。撤退すると敵シンボルは戻り、出会った敵は消える）。
- 加わるのはその敵 1 体だけ（出現数・お供は付かない）。フィールドで削った HP も持ち込む。
- 加われる数は「その場で敵が立てる枠（上限 6）− 触れた組の数」。**狭い所ほど少ない**。
- 0 にすると巻き込まない。

### 誰が戦闘に入るか

| 人 | 入るとき |
| --- | --- |
| 先頭 | いつも |
| ほかの仲間 | 先頭から `fieldBattle.together` マス（既定 5）以内にいるとき |
| 加勢 NPC | 同じ距離以内にいて、倒れておらず、`battle` が false でないとき（客として味方の後ろ） |

- イベントの戦闘は仲間みんなが入り、加勢 NPC は入らない。
- 戦闘に入った仲間がみんな倒れたら負け（ゲームオーバー）。経験は今までどおり隊列みんなに入る。

## 7. 撤退（段階 2）

- 特技「撤退」（`skills.json` の `retreat`。種類 `retreat`。MP 3。メイナがはじめから覚える）。
- **必ず成功**して MP を払う。
- 使えるのは**敵シンボルとの戦い**（ランダムエンカウントでも敵シンボルを巻き込んでいれば）と、**`chase` を書いたイベントの戦闘**だけ。ほかでは押せない（選ばれても「ここでは てったい できない！」で MP は払わない）。
- 撤退したら:
  - それまでに倒した敵は、勝ったときと同じく経験・お金・討伐・図鑑に数える。
  - 生き残りのいる敵シンボルは、触れた（巻き込まれた）ときのマスへ戻る。HP は同じ敵の生き残りの一番多い HP（シンボルの敵がいなくてお供だけ残ったら満タン）。
  - 戻った敵は、戻った時に「！」を出し、`fieldBattle.retreatStun` ミリ秒（既定 500）怯んで、解けたらすぐ動く（2026-11-08。前は怯み 1.5 秒のあとに「！」で 0.5 秒止まっていた）。怯みが解けて 0.3 秒たつまでは、触れても戦闘にならない。
  - 組がみんな倒れたシンボルは戻らない。
- 文は「〇〇 の 撤退！」「いったん ひいて たてなおす！」「いったん ひいた！」。演出は逃げると同じ。

### イベントの戦闘から撤退する（GS-307）

イベントの `battle` 命令に `chase` を書いた戦闘（いまは cave_hunt のグレートベア）だけ。

- 撤退すると、イベントは止まったまま歩けるようになる。`chase` の NPC が戦闘の残り HP のまま、**見失わず、置き場からの距離の制限もなく、壁を回り込んで**追ってくる。範囲の技も使う。
- **コマンド戦闘で勝っても、フィールドで倒しても**、イベントの続き（勝ったときの枝とその後）が動く。フィールドで倒したときの経験・お金も全額。
- 追われているあいだのコマンド戦闘も撤退できる。また追ってくる。
- **マップを出たら、イベントはそこで終わる**。物語は進まないので、もう一度起こすと最初から始まる。cave_hunt は初回の会話の最後にセルフスイッチ「挑んだ」を立て、2 回目からは `if` で短い掛け合いだけにして戦闘へ入る（データだけ。2026-11-07）。
- 追われているあいだは、ほかのイベントは起きない。メニューとセーブは使える（読み直すとイベントは最初から）。
- `noEscape: true` を書いた戦闘は「逃げる」を押せない。追われているあいだのコマンド戦闘にも効く。
- 熊（`BOSS_GreatBear`）はイベントの前はただの置物（敵シンボルではない）。イベントの場所に入るとイベントが始まる。
- `chase` の NPC は**戦闘のあいだフィールドから隠す**（敵シンボルと同じ。置物は舞台で自動では隠れないため）。舞台を片付けると出し直すので、撤退したらそのまま追ってくる。勝ったら `win` の枝の `hide` で消える。

## 8. 仲間の作戦（段階 3）

隊列ぜんぶで 1 つ。C キーで 戦わない → 移動・迎撃 → 移動・攻撃 → 自由に戦闘 → 待機・迎撃 と回る（メニューの「作戦」でも選べる）。**セーブには入らない**（読み込むと「戦わない」）。

| 作戦 | 動き |
| --- | --- |
| 戦わない | 今までどおり後ろを付いて歩く。攻めない。離れていた人は列へ戻る |
| 移動・迎撃 | 6 マス以内に**交戦中**の敵シンボルがいれば、列を離れて近づき攻める。いなくなれば列へ戻る |
| 移動・攻撃 | 6 マス以内の敵シンボルを、**気づいていなくても**列を離れて攻める。ただし先頭からも 6 マス以内の敵だけ（隊列の近くで戦う）。いなくなれば列へ戻る |
| 自由に戦闘 | 10 マス以内で敵シンボルを見つけたら（気づいていなくても）、**先頭から離れても**攻め続ける。見つからなくなれば列へ戻る。離れたまま戦闘が始まると、その戦闘には入らない |
| 待機・迎撃 | その場に留まる。届く敵シンボルは交戦中でなくても攻める |

- 攻撃は 1.2 秒に 1 回。中身はその人の「使う技」（MP が足りなければ素手）。ダメージ・怯み・取り分は ☐ と同じ。
- 歩く速さは 4.2 マス／秒（主人公の歩きと同じ）。
- 倒れた仲間・イベントが置いた仲間は動かない。イベントの最中は「戦わない」。
- 離れて動いている仲間は、戦闘が始まったときに離れすぎていると戦闘に入らない（上の 6.）。

## 9. 加勢する NPC（段階 4）

マップの NPC を、周りの敵と戦う味方にする。`mapNpcs.json` のその NPC に `ally` を書く（台帳エディタ「マップ構成」→ NPC の設定「加勢」）。今はどのマップにも置いていない。

| 項目 | 意味 | 既定 |
| --- | --- | --- |
| `member` | 借りる仲間（`party.json` の人）。能力・技・フィールドアタック・戦闘の絵と顔・名前を借りる | 必須 |
| `level` | 借りるときのレベル（1〜99） | 1 |
| `range` | 置き場から敵を探す距離（1〜16 マス） | 6 |
| `battle` | コマンド戦闘にも入るか | 入る |

- フィールドの姿はマップの NPC の絵のまま。敵シンボル（`enemy`）とは一緒に書けない。
- **フィールド**: 置き場から `range` 以内の敵シンボル（交戦中でなくても）のうち一番近いものへ歩き、1.2 秒に 1 回攻める（MP は使わない）。いなくなれば置き場へ戻る。
- 敵の範囲の技は加勢 NPC にも当たる。**HP 0 で倒れたら、そのマップにいるあいだは立ち止まったまま**。マップに入り直すと満タンで戻る。
- **コマンド戦闘**: 客として味方の後ろに入る。手は聞かず、毎ターン HP の一番少ない敵を通常攻撃で殴るだけ（技は使わない）。経験は入らない。HP・MP は戦闘のあとフィールドへ持ち帰る。味方がみんな倒れても、客が立っていれば戦闘は続く。

## 10. 設定の置き場（一覧）

| 何を | 台帳 | 台帳エディタ |
| --- | --- | --- |
| 技のフィールドでの使い方（形・範囲・予兆・間隔・MP・絵） | `skills.json` の技の `field` | 戦闘 → 技 |
| 仲間の「使う技」 | `party.json` の `members.<人>.fieldAttack` | ステータス → 仲間 |
| 素手の使い方 | `battleSettings.json` の `normalAttack.party.field` | 戦闘 → 通常攻撃 |
| フィールドで倒したときの取り分 | `battleSettings.json` の `rates.fieldKill`（0〜1。既定 0.5） | 戦闘 → 共通 |
| 交戦中に倒したときの経験 | `battleSettings.json` の `rates.fieldEngaged`（0〜1。既定 1） | 戦闘 → 共通 |
| 巻き込む距離 | `battleSettings.json` の `fieldBattle.join`（0〜12。既定 4） | 戦闘 → 共通 |
| 撤退のあとの怯み | `battleSettings.json` の `fieldBattle.retreatStun`（0〜10000 ミリ秒。既定 500） | 戦闘 → 共通 |
| 離れたとみなす距離 | `battleSettings.json` の `fieldBattle.together`（1〜30。既定 5） | 戦闘 → 共通 |
| 敵シンボル・気づいたときの動き | `mapNpcs.json` の `enemy`・`notice` | マップ構成 → NPC の設定 |
| 加勢 NPC | `mapNpcs.json` の `ally` | マップ構成 → NPC の設定 |
| フィールドアタックの禁止 | `maps.json` の `fieldAttack: false` | マップ構成 → 戦闘 |
| いつも舞台の点で戦う | `maps.json` の `battleAt: "stage"` | マップ構成 → 戦闘 |

## 11. まだ無いもの・決めていないこと

- 交戦中の BGM の切り替え・メニューの制限。
- 敵の飛ばす技・近接の技（敵が使えるのは範囲の形だけ）。
- ふだんの追う敵の回り込み（道探しをするのは、撤退のあと追ってくる敵だけ）。
- 加勢 NPC の技の使用・作戦。加勢 NPC への経験。
- 作戦のセーブ。
- 加勢 NPC を置いたマップ（台帳に例が無い）。
- 範囲の技を使う敵シンボルを置いたマップ（グレートベアは cave_hunt で撤退したあとだけ追ってくる）。
